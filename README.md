# Game Dev AI Tool

게임을 만드는 사람이 **AI 팀**을 부리게 해 주는 프로그램입니다.
여러분은 **총괄**(AI 하나)하고만 이야기합니다. 총괄이 기획 · 개발 · 아트 · 사운드 · QA 같은 **역할**(각자 따로 일하는 AI)을 만들어 일을 나눠 맡기고, 결과를 모아 알려 줍니다. 여러분은 프로그램 창에서 지켜보다가, AI 가 물어보는 것(「내가 정할 것」)에만 답하면 됩니다.

```
나 ──말── 총괄(AI) ──일을 나눠 맡김──▶ 역할들(기획 · 개발 · 아트 … 각자 AI)
 ▲                                          │
 └──── 프로그램 창: 대화 · 진행 상황 · 「내가 정할 것」 ◀── 결과
```

- AI 는 **여러분의 Claude 구독**(GPT 역할을 쓰면 ChatGPT 구독도)으로 돕니다. 따로 내는 돈은 없고, 여러분 구독의 사용량을 씁니다.
- 프로젝트 문서는 **위키**로 쌓입니다. 원본(기획서 · 회의록)을 넣으면 AI 가 정리하고, 옵시디언으로 그래프처럼 볼 수 있습니다.
- 모든 것이 **여러분 PC 에서** 돕니다. 만든 사람에게 아무것도 보내지 않습니다.

## 필요한 것

| 무엇 | 비고 |
|---|---|
| Windows 10 또는 11 (64비트) | Mac 은 아직 안 됩니다 |
| 인터넷 | 설치와 AI 사용에 필요합니다 |
| **Claude 유료 구독(Pro 이상)** | AI 가 이 구독으로 돕니다. 쓰는 만큼 구독의 사용량이 줄어듭니다 |
| ChatGPT 유료 구독(Plus 이상) — 선택 | GPT 역할을 같이 쓸 때만. Claude 사용량이 바닥나면 GPT 로 이어서 일하게 할 수도 있습니다 |
| 디스크 1GB 쯤 | 음성 입력을 켜면 더 듭니다 |

## 설치 — 세 번이면 끝

1. **받기** — [Releases](https://github.com/JeahanPark/game-dev-ai-tool/releases) 에서 맨 위 판의 `Game-Dev-AI-Tool-<판>.zip` 을 받습니다.
2. **풀기** — 알기 쉬운 곳에 풉니다(예: `C:\Game Dev AI Tool`). OneDrive 로 동기화되는 폴더(바탕화면 · 문서가 그럴 때가 많습니다)는 피합니다.
3. **`설치.cmd` 더블클릭** — 나머지는 창이 물어보는 대로 따라 하면 됩니다.

> 「Windows의 PC 보호」 파란 창이 뜨면 **추가 정보 → 실행** 을 누릅니다(인터넷에서 받은 파일이라 한 번 뜹니다).

설치 창이 하는 일:

| 차례 | 무엇 | 여러분이 할 일 |
|---|---|---|
| 1 | 파이썬이 없으면 깝니다 | 아무 키나 누르기 |
| 2 | AI 를 부르는 부품을 넣습니다 | 기다리기(처음에는 몇 분) |
| 3 | **Claude 로그인** — 브라우저가 열립니다 | 자기 Claude 계정으로 로그인하고 설치 창으로 돌아오기 |
| 4 | 「GPT 도 쓸까요?」 | `y` 면 GPT 부품 · Codex 를 깔고 **ChatGPT 로그인** 브라우저가 열립니다 |
| 5 | 「옵시디언도 깔까요?」 | `y` 면 위키를 보는 무료 앱 옵시디언을 깝니다 |
| 6 | **게임 프로젝트 폴더 고르기** | 내 게임 폴더를 고르기(드라이브 맨 위 · 사용자 폴더 자체는 안 됩니다) |
| 7 | 바탕화면에 「Game Dev AI Tool — <폴더 이름>」 아이콘을 만들고 프로그램 창을 엽니다 | 끝! |

- 도중에 멈추면 무엇이 안 됐는지 한 줄이 뜹니다. 고친 뒤 `설치.cmd` 를 다시 더블클릭하면 된 데부터 이어서 합니다.
- GPT · 옵시디언 답을 바꾸고 싶으면 설치한 폴더의 주소창에 `cmd` 를 쓰고 Enter → 뜬 창에 `설치.cmd ask` 를 칩니다(다시 물어봅니다).
- 다른 게임 폴더도 쓰려면 `설치.cmd` 를 다시 더블클릭하고 그 폴더를 고릅니다. 아이콘이 하나 더 생깁니다.

## 처음 써 보기

바탕화면 아이콘을 더블클릭하면 프로그램 창이 뜹니다.

| 자리 | 무엇 |
|---|---|
| 왼쪽 | 세션 목록 — 맨 위가 총괄, 아래가 역할들. 색과 글로 「일하는 중 · 기다림 · 내 확인 필요」를 보입니다 |
| 가운데 | 고른 세션과의 대화. 일하는 동안 입력칸 위에 「17초 · 생각 중」처럼 지금 무엇을 하는지 나옵니다 |
| 오른쪽 | 그 세션의 일 · 결과물 · 바뀐 파일 · 인계 · 역할 글 |
| 「내가 정할 것」 | AI 가 여러분에게 묻거나 승인을 청하는 카드. 답하면 일이 이어집니다 |

총괄에게 이렇게 말해 보세요:

- 「이 게임 폴더를 살펴보고, 필요한 역할을 만들어 줘」
- 「기획 역할에게 1장 레벨 기획서를 맡겨」
- 「wiki/raw/회의록.md 넣어」 · 「주인공 이름이 뭐였지? 위키에서 찾아 줘」
- 「오늘 한 일을 정리해 줘」

- **창을 닫아도 AI 는 뒤에서 계속 일합니다.** 다 끄려면 **설정 → 프로그램 끄기**(두 번 누릅니다).
- 다시 열 때는 바탕화면 아이콘을 더블클릭합니다.

## 위키와 옵시디언

프로젝트 폴더에 `wiki` 폴더가 생깁니다.

| 자리 | 누가 | 무엇 |
|---|---|---|
| `wiki\raw\` | **여러분** | 원본을 넣는 곳(기획서 · 회의록 · 참고 글 · 그림). AI 는 읽기만 하고 고치지 않습니다 |
| `wiki\pages\` | AI | 원본을 정리한 페이지. 서로 `[[링크]]` 로 이어집니다 |
| `wiki\index.md` · `wiki\log.md` | AI | 모든 페이지의 목록 · 언제 무엇을 했는지의 기록 |

- 원본을 넣고 총괄에게 「넣어」 → AI 가 페이지를 만들고 목록과 기록을 고칩니다.
- 물어보면 위키에서 찾아 **출처를 붙여** 답합니다. 가끔 「점검해」 하면 서로 어긋나거나 낡은 내용을 찾습니다.
- **옵시디언으로 보기:** 옵시디언을 열고 「폴더를 보관함으로 열기」 → 프로젝트의 `wiki` 폴더를 고릅니다. 그래프 보기에서 페이지가 어떻게 이어지는지 보입니다. 옵시디언의 Web Clipper(브라우저 확장)로 웹 글을 `raw` 에 바로 넣을 수도 있습니다.
- 옵시디언은 보는 도구일 뿐입니다. 없어도 AI 는 위키를 씁니다.

## AI 를 내 방식대로 — Custom

기본 규칙은 그대로 두고, 그 위에 내 규칙을 **덧붙일** 수 있습니다. 프로그램 창 오른쪽 「역할 글」 탭에서 「고치기」를 누르거나, 총괄에게 말하면(승인 카드가 뜹니다) 됩니다.

| 범위 | 예 |
|---|---|
| 모든 프로젝트 | 「답은 짧게」 |
| 이 프로젝트 | 「이 게임의 말투는 귀엽게」 |
| 이 역할 | 사운드 역할에 「배경음악은 Suno, 효과음은 ElevenLabs 로」 |

도구 이름 대신 **할 일**만 적으면 Claude · GPT 둘 다 알아듣습니다.

## 알아 두면 좋은 것

- **총괄의 AI 모델** — 설치할 때 Claude 구독을 보고 정합니다. Max 이상이면 가장 좋은 모델(Opus · 최대 세기), Pro 면 사용량을 아끼게 계정의 기본 모델입니다. 바꾸려면 게임 폴더의 `team\총괄\역할.md` 를 메모장으로 열어 맨 위의 `model:` · `effort:` 줄을 고칩니다(예: `model: claude-opus-5-5` · `effort: high`).
- **사용량** — 설정의 「사용량」에서 Claude · GPT 의 주간 사용량을 봅니다. Claude 가 한도에 가까우면 새 일을 잠시 멈추고, 총괄에 GPT 를 대체로 정해 두었다면 GPT 로 이어서 일합니다.
- **폰 · 다른 PC 에서 쓰기(선택)** — 설정 → 「원격 기기」에서 켭니다. Tailscale 이라는 프로그램을 씁니다. Tailscale 무료 요금제는 개인 · 비상업용이니, 회사 일이라면 요금제를 살펴보세요. 켜기 전에 창이 조건을 알려 줍니다.
- **개인정보** — 프로그램은 여러분 PC 에서만 돕니다. 다만 AI 가 일하려고 읽는 파일 내용은 Anthropic(Claude) · OpenAI(GPT)로 보내집니다(각 회사의 약관대로). 비밀번호 · 키 같은 비밀 파일은 프로젝트 폴더에 두지 마세요.
- **바뀐 파일과 커밋** — git 을 쓰는 프로젝트라면 「바뀐 코드」 탭에서 AI 가 고친 것을 보고, 커밋 · 푸시는 여러분이 승인해야 됩니다.

## 새 판으로 올리기

1. [Releases](https://github.com/JeahanPark/game-dev-ai-tool/releases) 에서 새 zip 을 받아 **같은 폴더에 덮어서** 풉니다.
2. `설치.cmd` 를 더블클릭합니다. 프로젝트 · 설정 · 위키는 그대로 남습니다.
3. 열어 둔 폰 · PC 화면은 새 판을 알아채 스스로 새로 열립니다(1.4.1 부터 — 1.4.0 이하에서 올릴 때만 한 번 닫았다 다시 엽니다).

## 지우기

설치한 폴더와 바탕화면 아이콘을 지우면 됩니다. 게임 프로젝트 안의 `gaf.json` · `team\` · `wiki\` · `.gaf\` 는 남으니, 필요 없으면 따로 지웁니다.

## 문제가 생기면

| 겪는 일 | 해 볼 것 |
|---|---|
| 설치가 멈췄다 | 창의 마지막 줄을 읽고 고친 뒤 `설치.cmd` 를 다시 더블클릭 |
| 프로그램 창이 안 뜬다 | 바탕화면 아이콘을 다시 더블클릭 |
| AI 가 대답이 없다 | 왼쪽 목록의 상태와 설정 → 「사용량」을 확인. 그래도 안 되면 프로그램 끄기 후 다시 켜기 |
| 무엇이 안 됐는지 모르겠다 | 설치한 폴더의 주소창에 `cmd` → `.venv\Scripts\python.exe -m gaf doctor --root "<게임 폴더>"` — 안 된 것과 고치는 법을 한 줄씩 알려 줍니다 |
