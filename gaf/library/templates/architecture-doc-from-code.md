> **쓰는 법** — 누가 채우나: 기술 역할(예: 리드 프로그래머)이 코드를 읽고 쓴다 · 언제: 결정 글 없이 이미 만들어진 구조를 기록할 때, 기존 프로젝트를 들일 때 · 줄여도 되는 절: 대안 2 · 스레드 안전(한 스레드만 쓰면 한 줄) · 부록 코드 조각 · 사람이 정할 것: 없다(기술 기록이다). 다만 코드만으로 알 수 없는 「왜」는 지어내지 않는다 — 「열린 질문」에 적고, 누구에게 물을지는 총괄이 정한다. 채운 문서에서는 이 칸을 지운다.
>
> 모든 이유 · 배경에 출처 표시를 붙인다: **[코드]** 코드에서 읽음(파일 · 줄) · **[추측]** 코드에서 미루어 봄 · **[확인]** 사람이나 총괄에게서 받은 답(누가 · 언제). 추측을 확인처럼 쓰지 않는다.
