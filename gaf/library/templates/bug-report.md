> **쓰는 법** — 누가 채우나: QA 테스터(심각도는 권고로 적고, 우선순위는 총괄이 정한다) · 언제: 버그 설명이 들어왔을 때, 또는 코드를 읽다 잠재 버그를 찾았을 때 · 줄여도 되는 절: 기술 맥락 · 관련 건 · 메모(모르면 「—」) · 사람이 정할 것: 없다(S1 · S2를 안 고치기로 받아들이는 것만 출시 위험이라 사람이 정한다).
>
> 번호는 프로젝트의 방식으로 한곳에서 받는다(고정 형식을 강요하지 않는다 · 여럿이 따로 매기지 않는다). 신고자 칸에는 신고자가 밝힌 이름만 적는다 — 메일 주소 · 계정 ID 같은 개인 식별 정보를 세션 정보에서 가져다 넣지 않는다. 모르는 칸은 비우지 말고 「—」나 「모름」을 적는다. 채운 문서에서는 이 칸을 지운다.
