**왜 있나**: 화면 명세가 올림 상태 · 누름 움직임 · 초점 · 키보드 처리 · 낭독기 안내를 화면마다 다시 쓰지 않고 「버튼(주) 패턴을 쓴다」고만 말하게 한다. 다시 쓰는 상호작용의 원본은 여기 한 곳이다 — 동작이 바뀌면 여기서 바꿔 모든 곳에 적용한다. 살아 있는 문서라 새 화면을 설계하며 패턴이 는다. 새 상호작용을 설계하기 전에 여기를 먼저 본다.

**패턴 상태**: 초안(규격만 있고 구현 · 확인 전) · 안정(구현 · 시험하고 출시한 화면 하나 이상에서 확인) · 폐기 예정(쓰는 곳을 옮기는 중 — 새 화면에 쓰지 않는다).

## 개요

### 이 목록을 쓰는 법

- **화면을 설계할 때**: 새 상호작용을 지어내기 전에 색인을 훑는다. 맞는 패턴이 있으면 화면 명세에 이름으로 가리킨다(예: 「확인 버튼은 버튼(주) 패턴」). 없으면 새 패턴을 그것을 쓰는 화면 명세보다 먼저 또는 함께 여기에 적는다.
- **화면을 구현할 때**: 「<패턴 이름> 패턴」이라 하면 여기서 전체 규격을 찾는다. 구현 메모는 엔진 쪽 안내이고, 접근성 칸은 빼면 안 되는 요구다.
- **화면 명세를 검토할 때**: 누르는 부품마다 패턴을 가리키거나 자기 규격을 다 적었는지 본다. 「보통 버튼」 · 「늘 하던 대로」는 가리킴이 아니다.
- **패턴을 고칠 때**: 「안정」 패턴을 바꾸면 쓰는 모든 화면이 바뀐다. 쓰는 곳을 모두 찾아(화면 명세에서 이름 검색) 영향을 정하고, 검토한 역할 · 판정 · 근거를 남기고, 구현을 바꾸기 전이나 같이 이 문서를 고친다.

## 패턴 목록

### 패턴 색인

새 패턴을 더할 때마다 줄을 더한다. 「쓰는 화면」 칸이 쓰는 곳의 기록이다 — 새 화면이 패턴을 쓰면 고친다.

### 기본 조작 패턴

전체 규격(상태표 예 · 접근성 · 구현 때 볼 것)은 `templates/interaction-pattern-library-guide-standard-controls`에 있다 — 지금 쓰는 패턴만 읽는다.

#### 버튼(주)
분류 입력 · 상태 초안 · 쓸 때: <화면에서 가장 중요한 동작 — 한 번에 하나만 보인다> · 쓰지 말 때: <다른 · 보조 동작 · 파괴 동작 · 화면의 주된 의도가 아닌 것>
- 상태표 줄: 기본 · 올림 · 초점 · 누름 · 못 씀 · 처리 중
- 접근성: <키보드 · 패드 · 화면 낭독기 · 색약 · 터치 영역 요구> · 구현 메모: <엔진 쪽 안내>

#### 버튼(보조)
분류 입력 · 상태 초안 · 쓸 때: <다른 동작 · 취소 — 주 버튼보다 가볍게> · 쓰지 말 때: <파괴 동작 · 화면의 가장 중요한 동작>
- 상태표 줄: 기본 · 올림 · 초점 · 누름 · 못 씀
- 접근성: <버튼(주)와 같은 기준 · 대화상자에서 취소 입력에 묶는지> · 구현 메모: <주 · 보조의 위치를 화면마다 같게>

#### 버튼(파괴)
분류 입력 · 상태 초안 · 쓸 때: <플레이어 데이터나 진행을 잃는 되돌릴 수 없는 동작> · 쓰지 말 때: <되돌릴 수 있거나 결과만 큰 동작>
- 상태표 줄: 기본 · 올림 · 초점 · 누름(첫 누름) · 못 씀
- **꼭 지킬 것**: 버튼(파괴)는 동작을 바로 실행하지 않는다. 늘 확인 대화상자를 연다. 예외는 없다.
- 접근성: <화면 낭독기가 되돌릴 수 없다는 것을 읽는다> · 구현 메모: <엔진 쪽 안내>

#### 토글
분류 입력 · 상태 초안 · 쓸 때: <지금 상태가 한눈에 보여야 하는 켬 · 끔 설정> · 쓰지 말 때: <보기가 셋 이상 · 한 번 하고 끝나는 동작 · 설명이 필요한 선택>
- 상태표 줄: 끔(기본) · 올림 · 초점 · 켜짐 · 꺼짐 · 못 씀
- 접근성: <켜고 끄는 입력 · 낭독기의 역할 · 상태 규칙 · 상태 글 요구> · 구현 메모: <움직임 줄이기에서의 동작>

#### 밀대
분류 입력 · 상태 초안 · 쓸 때: <범위와 상대 위치가 뜻이 있는 이어진 값> · 쓰지 말 때: <정확한 값 입력 · 짧은 보기 목록 · 켬 · 끔>
- 상태표 줄: 기본 · 올림 · 초점 · 끌기 · 키보드 · 방향 버튼 조절 · 큰 걸음 조절 · 놓음 · 못 씀
- 접근성: <작은 걸음 · 큰 걸음 · 최소 · 최대 입력 · 값을 읽는 안내 · 숫자 값 표시> · 구현 메모: <엔진 쪽 안내>

#### 펼침 목록
분류 입력 · 상태 초안 · 쓸 때: <정해진 보기 <프로젝트 값>개 안팎 · 닫혔을 때는 고른 것만 보인다> · 쓰지 말 때: <둘 중 하나 · 보기가 너무 많을 때 · 보기를 견주는 게 중요할 때>
- 상태표 줄: 닫힘(기본) · 올림 · 초점 · 열림 · 목록 줄 초점 · 고름 · 고르지 않고 닫음 · 못 씀
- 접근성: <목록 안 이동 · 낭독기 역할 · 펼침 · 접힘 안내 · 열리는 위치 규칙> · 구현 메모: <엔진 쪽 안내>

#### 목록 줄
분류 배치 · 입력 · 상태 초안 · 쓸 때: <세로 스크롤 목록의 고를 수 있는 줄> · 쓰지 말 때: <2차원 격자 · 고를 수 없는 내용 줄>
- 상태표 줄: 기본 · 올림 · 초점 · 선택됨(남음) · 누름 · 못 씀
- 접근성: <끝에서 도는지 · 낭독기 역할과 위치 안내 · 최소 줄 높이> · 구현 메모: <초점 때 그 줄이 보이게 스크롤>

## 애니메이션 기준

모든 패턴에 적용한다. 패턴이 말하는 곡선은 여기서 정한 것이다. 시간이 같아야 UI가 하나로 설계한 체계처럼 느껴진다.

| 애니메이션 | 길이(ms) | 곡선 | 메모 |
|---|---|---|---|
| 버튼 올림 · 초점 들어옴 | <프로젝트 값> | 예: ease-out | 빠르게 — 굼뜨지 않게 |
| 버튼 올림 · 초점 나감 | <프로젝트 값> | 예: ease-in | 들어올 때보다 조금 빠르게 |
| 버튼 누름(작아짐) | <프로젝트 값> | 예: ease-in | 바로 느껴지게 |
| 버튼 뗌(돌아옴) | <프로젝트 값> | 예: ease-out | 살짝 튀는 느낌 |
| 화면 쌓기 · 빼기 | <프로젝트 값> | 예: ease-in-out | 오른쪽에서 들어오고 오른쪽으로 나간다 |
| 모달 열기 · 닫기 | <프로젝트 값> | 예: ease-out · ease-in | 가운데서 커지고, 닫힐 때가 더 빠르다 |
| 알림 들어옴 · 나감 | <프로젝트 값> | 예: ease-out · ease-in | 화면 가장자리에서 |
| 탭 바꾸기 | <프로젝트 값> | 예: ease-in-out | 내용이 교차 페이드하거나 미끄러진다 |
| 툴팁 나타남 · 사라짐 | <프로젝트 값> | 예: ease-out · ease-in | 나타나기 전 지연 <프로젝트 값> |
| 진행 막대 채움 | <프로젝트 값> | 예: ease-out | 값이 부드럽게 바뀐다 |
| 값 깜박임(피해 · 획득) | <프로젝트 값> | 예: linear | 짧고 눈에 띄게 |
| 대사 글자 드러남(글자마다) | <프로젝트 값> | 예: linear | 접근성 설정에서 바꿀 수 있다 |
| HUD 피해 깜박임 | <프로젝트 값> | 예: linear | 바로 덮는 색 |

**움직임 줄이기**: 움직임 줄이기를 켜면(접근성 요구 문서 참고) 미끄러짐 · 커짐 애니메이션은 페이드로 바뀌고, 페이드 길이는 <프로젝트 값>만큼 줄며, 도는 애니메이션(끝을 모르는 진행 표시 · 맥박)은 멈춘 표시로 바뀐다.

## 소리 기준

조작하는 사건마다 소리 피드백이 있어야 한다. 소리는 꾸밈이 아니라 주요 피드백 길이다. 여기 적는 것은 사건의 분류이고, 실제 소리 자료는 사운드 기준서에서 정한다. 이 표로 사운드 디자이너와 UI 프로그래머가 같은 낱말을 쓴다.

| 조작 사건 | 소리 분류 | 메모 |
|---|---|---|
| 버튼 올림 · 초점 | UI 올림 | 은은하고 짧게 · 빨리 옮겨 다녀도 지치지 않게 |
| 버튼(주) 확인 | UI 확인 — 주 | 보조 확인보다 조금 두드러지게 · 「가자」의 소리 |
| 버튼(보조) 취소 · 뒤로 | UI 취소 | 음이 살짝 내려간다 · 「돌아간다」의 소리 |
| 버튼(파괴) — 확인 대화상자 열기 | UI 경고 | 보통 확인과 다르게 · 짧게 눈길을 끈다 |
| 확인 대화상자 — 파괴 동작 확인 | UI 확인 — 파괴 | 끝맺는 · 조금 무거운 소리 |
| 토글 켬 · 끔 | UI 토글 켬 · 끔 | 같은 소리 가족 — 끔은 조금 납작하게 |
| 밀대 조절 | UI 밀대 | 끄는 동안 은은하게 · 방향 버튼 한 걸음에 한 번 · 지치지 않게 |
| 펼침 목록 열기 · 고르기 | UI 펼침 · UI 고름 | 여는 느낌 · 확인하는 느낌 |
| 탭 바꾸기 | UI 탭 | 가로로 옮기는 느낌 · 세로 이동과 다르게 |
| 모달 열기 · 취소로 닫기 | UI 모달 열림 · 닫힘 | 보통 이동보다 두드러지게 · 앞 맥락으로 돌아가는 느낌 |
| 알림 — 정보 · 업적 · 경고 | UI 알림 · UI 업적 · UI 경고 — 알림 | 정보는 배경 수준 · 업적은 축하하되 끊지 않게 · 경고는 오류와 다르게, 놀라게 하지 않게 |
| 오류 상태 | UI 오류 | 다정하지만 분명하게 · 거친 버저가 아니다 |
| 성공 확인 | UI 성공 | 깔끔하고 기분 좋게 |
| 능력 씀 · 피해 받음 · 아이템 획득 · 레벨 업 | 플레이 — 능력 · 피해 · 획득 · 성장 | 메뉴가 아니라 게임 손맛의 소리 — 사운드 기준서를 따른다 |
| 대사 넘김 | UI 대사 | 은은하게 · 글자가 드러나는 박자에 맞춘다 |
