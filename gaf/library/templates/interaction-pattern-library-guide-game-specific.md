# 상호작용 패턴 길잡이 게임 화면

패턴마다 쓸 때 · 상태표 · 접근성을 보인다. 시간 · 크기 · 개수는 모두 예이고, 이 게임 값은 틀의 「애니메이션 기준」 표와 <프로젝트 값>에서 정한다. 엔진 구현은 프로젝트의 엔진 참조 문서와 그 엔진 전문가 역할이 정한다.

#### 인벤토리 칸

**쓸 때**: 인벤토리 격자의 모든 아이템 칸 — 빈 칸 · 찬 칸 · 장비 중인 칸 · 잠긴 칸. 칸은 틀이고 아이템 아이콘은 내용이다.

| 상태 | 보이는 것 | 메모 |
|---|---|---|
| 빈 칸 | 옅은 칸 테두리 · 내용 없음. 못 씀과 다르다 — 빈 칸은 아이템을 받는다 | 빈 칸을 아예 안 보이게 하지 않는다 — 격자 크기를 잃는다 |
| 찬 칸 | 아이콘이 칸 대부분을 채움 · 쌓인 수(오른쪽 아래) · 품질 테두리(색 + 아이콘) · 장비 중 표시(오른쪽 위) | |
| 초점 | 초점 테두리 · 지연(<프로젝트 값>) 뒤 툴팁 | |
| 선택됨 | 더 굵거나 대비 큰 테두리 | 여러 개를 고를 수 있을 때 |
| 끌기 출발 | 칸이 흐려지고 끄는 그림이 포인터를 따름 | 끌기 전체는 격자 칸 패턴을 따른다 |
| 잠김 | 자물쇠 덮개 · 조작 없음 · 뒤에 아이템을 흐리게 보일 수 있다 | 잠긴 장비 칸 · 추가 내용 등 |
| 강조 | 테두리가 빛나며 맥박 · 퀘스트 아이템 · 새 아이템 | 움직임 줄이기에서는 맥박 대신 멈춘 표시 |
| 재사용 대기 덮개 | 12시 방향부터 시계 방향으로 줄어드는 원형 덮개 | 칸이 재사용 대기가 있는 아이템일 때만 |

**접근성**: 쌓인 수와 품질 단계는 색 말고 글이나 아이콘으로도 보인다. 툴팁이 주된 접근성 수단이다 — 키보드와 화면 낭독기로 닿게 한다. 잠긴 칸은 낭독기에 「잠김」을 알린다. **구현 때 볼 것**: 품질 테두리를 아이콘 전체 색조 바꾸기로 하지 않는다 — 아이콘 색까지 바뀐다.

#### 능력 아이콘

**쓸 때**: HUD 능력 막대의 버튼 · 능력 나무의 마디 · 쓸 수 있는지를 보여야 하는 모든 능력 표시.

| 상태 | 보이는 것 | 메모 |
|---|---|---|
| 쓸 수 있음 | 진한 아이콘 · 아래에 묶인 키 이름 | |
| 재사용 대기 | 12시부터 시계 방향으로 줄어드는 원형 덮개 · 남은 시간이 <프로젝트 값>초 넘으면 가운데 숫자 | |
| 남은 충전 | 아이콘 아래 충전 점(예: 찬 점 셋 = 충전 셋) · 낭독기에는 숫자 | |
| 자원 부족 | 아이콘이 크게 흐려지고 테두리 · 키 이름도 흐려짐 | 재사용 대기와 다르다 — 시간이 아니라 자원이 막는다 |
| 잠김 · 아직 안 엶 | 아이콘 그림자만 · 자물쇠 표 · 툴팁에 여는 조건을 보일 수 있다 | |
| 쓰는 중 · 끌어 쓰는 중 | 테두리 맥박 · 원형 채움이 남은 시간을 보인다 | |
| 막 씀 | 짧게 작아졌다가 튀며 돌아옴 | 쓴 것을 확인하는 손맛 · 움직임 줄이기를 따른다 |

**접근성**: 재사용 대기 · 충전 정보는 모두 숫자 값이 있어야 한다 — 낭독기는 원형 덮개를 못 읽는다. 재사용 대기 숫자가 이를 채운다. 능력 이름과 설명은 툴팁으로 낭독기에 넘긴다.

#### 체력 · 자원 막대

**쓸 때**: HUD에서 계속 변하는 중요한 플레이어 자원 — 체력 · 마나 · 기력 · 보호막 · 연료.

| 사건 | 보이는 것 | 소리 | 길이 |
|---|---|---|---|
| 줄어듦(피해) | 채움이 줄고 짧게 깜박임 · 그림자 막대가 앞 값에 남았다가 새 값까지 줄어든다(피해 표시) | 피해 받음 — 양에 따라 다르게 | 줄어듦은 바로 · 그림자는 예: 500ms |
| 늘어남(회복) | 채움이 늘고 회복 색으로 짧게 깜박임(색약에 맞게 아이콘 · 빛을 함께) | 회복 | 예: 300ms |
| 문턱 아래 | 경고 색 · 테두리 맥박(움직임 줄이기에서는 멈춘 표) · 심장 소리를 둘 수 있다(소리만으로 알리면 화면 신호를 함께) | 낮은 체력 — 문턱 위로 오를 때까지 반복 | 계속 |
| 0 | 막대가 빔 · 짧게 흔들릴 수 있다 · 죽음 · 바닥남 사건 | 죽음 · 바닥남 | 예: 200ms |
| 최대 | 가득 참 · 짧게 빛남 | — | 예: 200ms |
| 넘침(보호막) | 원래 채움 밖에 보호막 색 조각이 따로 붙음 | 보호막 얻음 | 예: 200ms |

문턱 값은 <프로젝트 값>이다(원문 예: 25%). **접근성**: 지금 값을 숫자로 볼 수 있어야 한다(툴팁이나 늘 보이는 글, 또는 둘 다). 문턱 상태는 색 말고도 아이콘 · 깜박임 · 화면 경고로 알린다 — 경고 단계에는 색이 바뀌는 것과 따로 보이는 신호가 있어야 한다. **구현 때 볼 것**: 그림자 막대는 앞 값을 들고 천천히 줄어드는 뒷 막대와 새 값을 바로 보이는 앞 막대 둘로 만든다. 줄어드는 길이는 디자이너가 조절하는 값으로 뺀다.

#### 대화 상자

**쓸 때**: 말하는 이가 있는 모든 대사 — 인물 대화 · 음성 내레이션 · 인물이 전하는 튜토리얼 글.

**구조**: 말하는 이 얼굴이나 이름표(상자 위나 왼쪽) · 대사 본문 · 넘김 안내(오른쪽 아래) · 고를 수 있는 것: 모두 건너뛰기 버튼 · 음성 표시 · 자막 표시.

| 상태 | 보이는 것 | 입력 | 반응 | 길이 |
|---|---|---|---|---|
| 줄 들어옴 | 글자가 하나씩 드러남(타자 효과) · 접근성 설정이면 한 번에 나타남 | — | — | 빠르기는 접근성 설정 |
| 드러나는 중 | 글자가 나오는 중 · 넘김 안내는 숨거나 느리게 깜박임 | 넘김 입력 | 지금 줄 끝까지 바로 보인다(타자 효과 멈춤) | 바로 |
| 줄 끝 | 줄 전체 · 넘김 안내가 보이고 움직임 | — | — | — |
| 넘김 | 넘김 안내가 숨고 글이 사라지며 다음 줄 | 넘김 입력 — 키보드 · 패드 확인 버튼 · 마우스 클릭 | 다음 줄 | 예: 100ms |
| 선택지 나옴 | 대사 아래 선택 버튼 · 넘김 안내 숨음 · 초점이 첫 선택지로 | 방향 버튼 · 키보드로 고르고 확인 입력 | 선택 | 예: 150ms |
| 닫힘 | 상자가 사라짐 | 마지막 줄을 넘김 | 조종이 플레이어에게 돌아감 | 예: 200ms |
| 모두 건너뜀(있으면) | 짧은 확인 「대화를 건너뛸까?」 | 건너뛰기 입력 | 대화 뒤 상태로 | — |

**접근성**: 음성 대사의 자막 기본값은 프로젝트 접근성 요구 문서에서 정한다(원문은 이 패턴에서 「늘 켬」을, 접근성 틀에서는 「기본 끔」을 업계 표준이라 적었다 — 표준이라 쓰지 않고 사람이 정한다). 글자가 드러나는 빠르기는 플레이어 설정이다. 원문은 대사를 저절로 넘기지 말라고 한다 — 속도를 플레이어가 쥔다. 자동 넘김을 둘지는 사람이 정하고, 둔다면 끌 수 있게 한다. 말하는 이 이름은 늘 보인다. 선택지는 키보드 · 패드로 모두 옮길 수 있고 낭독기가 위치와 함께 읽는다. **구현 때 볼 것**: 넘김 입력 하나가 타자 효과 중이면 줄 끝으로, 아니면 다음 줄로 가게 한다. 대사 자료의 형식(파일 · 대화 도구)은 구조 결정 기록(ADR)으로 정한다.

#### 상황 동작 안내

**쓸 때**: 상호작용할 수 있는 것 가까이에 할 수 있는 일을 알리는 안내 — 「<버튼>으로 상자 열기」 · 「<버튼>을 누르고 있어 줍기」. 상호작용 영역에 들어오면 나오고 나가면 사라진다.

| 상태 | 보이는 것 | 메모 |
|---|---|---|
| 나타남 | 대상 기준점에서 살짝 떠오르며 서서히 나타남 | 움직임 줄이기에서는 떠오르지 않고 서서히만 |
| 대기 | 플랫폼에 맞는 버튼 아이콘 + 동작 이름 · 아이콘은 지금 입력 장치를 따른다(바꾸면 바뀐다) | 모든 플랫폼에 같은 버튼 이름을 박아 넣지 않는다 |
| 누르고 있음(누르기 입력) | 버튼 아이콘에 원형 채움이 진행을 보임 · 이름이 진행형 동사로(「여는 중…」) | |
| 못 함(막힘) | 아이콘이 흐려짐 · 까닭을 알면 이름에(「너무 무겁다」 · 「열쇠가 필요하다」) | 고를 수 있다 — 플레이어에게 뜻이 있는 까닭일 때만 |
| 사라짐 | 서서히 사라짐 | 상호작용 영역을 나갈 때 |

**접근성**: 버튼 아이콘에는 늘 글 이름표를 붙인다 — 아이콘만 두지 않는다(직접 버튼 이름을 바꾸거나 표준이 아닌 아이콘의 보조 조작기를 쓰는 플레이어가 있다). 캐릭터 체력이나 중요한 HUD 정보와 겹치지 않는 곳에 둔다. **구현 때 볼 것**: 안내가 카메라를 향하게 하고, 마지막으로 쓴 입력 장치를 알아내 아이콘을 바꾼다.

#### 피해 숫자

**쓸 때**: 전투 참가자 위에 떠오르는 피드백 숫자 — 보통 피해 · 치명타 · 회복 · 빗나감.

| 변형 | 보이는 것 | 메모 |
|---|---|---|
| 보통 피해 | 흰 숫자 · 보통 굵기 · 중간 크기 | |
| 치명타 | 더 크고(예: 1.5배) 굵게 · 주황이나 노랑(색약에 맞는지 확인) · 나타날 때 커졌다 돌아옴 | 크기만으로도 바로 알아보게 — 색에 기대지 않는다 |
| 회복 | 초록(색약 확인 — + 앞붙임과 위로 오르는 길을 색 말고 다른 표시로) | |
| 빗나감 · 피함 | 「MISS」 같은 글 · 회색 · 기울임 · 더 작게 | |
| 지속 피해 | 더 작게 · 상태 효과에 맞춘 다른 색 | |

**동작**: 맞은 곳에서 위로 떠오르고(예: 1초) 끝 무렵 흐려진다(예: 마지막 0.4초). 빠르게 연달아 맞으면 옆으로 엇갈려 겹치지 않게 한다. 화면에 동시에 보이는 수의 최대는 <프로젝트 값>(게임마다 정한다).

**접근성**: 피해 숫자는 보조 피드백일 뿐 — 전투 상태를 아는 유일한 길이면 안 된다. 체력 막대가 기준이다. 피해 숫자를 모두 끄는 선택을 둔다(시각적으로 버거운 플레이어가 있다). 꺼도 게임은 다 플레이되어야 한다. **구현 때 볼 것**: 숫자 개체를 미리 만들어 돌려 쓰고(풀), 나타날 때 옆으로 작게 무작위로 비켜 겹침을 줄인다.
