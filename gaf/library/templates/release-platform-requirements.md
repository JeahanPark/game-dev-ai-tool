> **쓰는 법** — 누가 채우나: QA 리드 · QA 테스터(대상 기기에서 실제로 해 본 결과) · 언제: 출시 점검표(`templates/release-checklist-template`) · 출시 준비표(`templates/launch-checklist`)를 채울 때 · 줄여도 되는 절: 대상이 아닌 기기의 블록은 옮기지 않는다. 대상 기기를 아직 안 정했으면 블록을 고르지 않고 「못 봄 — 아직 안 정함」으로 남긴다 · 사람이 정할 것: 대상 기기(돈 · 일정이 걸림).
>
> 총괄은 이 글과 함께 `templates/release-checklist-template`를 꺼낸다. 정식 출시에서는 `templates/launch-checklist`도 꺼내며, 프로젝트 문서 경로를 맡기는 글에 적는다.
>
> 이 블록에는 인증 · 상점 SDK 줄이 없다. 그것은 기기가 아니라 상점 · 플랫폼으로 고르는 인증 틀(콘솔 인증 점검(`templates/certification-console`) · Steam 출시 점검(`templates/certification-steam`) · itch.io 출시 점검(`templates/certification-itch`) · 인증 해당 없음 기록(`templates/certification-none`) · 인증 대상 미정 기록(`templates/certification-unknown`))에 있다. 상점 · 기기의 최신 요구는 「최신 공식 요구를 확인했나(언제 · 어디서)」 칸으로 남기고, 이 표를 인증 기준으로 쓰지 않는다. 채운 문서에서는 이 칸을 지운다.

# 기기별 출시 점검

출시 점검표(`templates/release-checklist-template`)에 적힌 대상 기기(PC · 콘솔 · 모바일 · 모두)의 블록만 옮긴다. 판정 칸: 통과 · 실패 · 못 봄 · 해당 없음(이유). 아직 정하지 않은 것은 「못 봄 — 아직 안 정함」으로 적는다.

### 기기 요구: PC
| 항목 | 판정 | 근거 · 이유 |
|---|---|---|
| 최소 · 권장 사양을 확인하고 적었다 | | |
| 키보드 · 마우스 조작이 모두 된다 | | |
| 컨트롤러 지원을 시험했다(예: Xbox · PlayStation · 일반 컨트롤러) | | |
| 해상도 바꾸기를 시험했다(예: 1080p · 1440p · 4K · 울트라와이드) | | |
| 창 · 테두리 없는 창 · 전체 화면이 모두 된다 | | |
| 그래픽 설정이 바르게 저장되고 불러와진다 | | |

### 기기 요구: 콘솔
| 항목 | 최신 공식 요구를 확인했나(언제 · 어디서) | 판정 | 근거 · 이유 |
|---|---|---|---|
| 플랫폼별 컨트롤러 버튼 안내가 바르게 보인다 | | | |
| 일시 중지 · 복귀가 바르게 된다 | | | |
| 사용자 바꾸기를 바르게 다룬다 | | | |
| 네트워크 끊김을 부드럽게 다룬다 | | | |
| 저장 공간이 가득 찬 상황을 다룬다 | | | |

### 기기 요구: 모바일
| 항목 | 최신 공식 요구를 확인했나(언제 · 어디서) | 판정 | 근거 · 이유 |
|---|---|---|---|
| 앱 마켓 지침 — 확인한 지침의 판과 날을 적는다(이 줄을 지침 통과로 읽지 않는다) | | | |
| 필요한 기기 권한마다 까닭을 적었다 | | | |
| 개인정보 방침이 연결돼 있고 정확하다 | | | |
| 데이터 안전 · 개인정보 표시 항목을 채웠다 | | | |
| 여러 화면 크기에서 터치 조작을 시험했다 | | | |
| 배터리 사용이 기준 안이다(<프로젝트 값>) | | | |
| 백그라운드 동작이 맞다(일시 중지 · 복귀 · 종료) | | | |
| 푸시 알림 권한을 바르게 다룬다 | | | |
| 앱 안 결제 흐름을 시험했다(해당할 때) | | | |
| 앱 크기가 마켓 한도 안이다(한도는 공식 문서로 확인) | | | |
