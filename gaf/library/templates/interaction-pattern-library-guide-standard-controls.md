# 상호작용 패턴 길잡이 기본 조작

패턴마다 쓸 때 · 쓰지 말 때 · 상태표 · 접근성을 보인다. 상태표의 「소리」는 틀의 소리 기준 분류다. 원문은 상태마다 시간(ms) · 배율 · 투명도 숫자를 적었다 — 여기서는 빼고 틀의 「애니메이션 기준」 표와 <프로젝트 값>에서 정한다. 역할 이름(「버튼」 · 「switch」 같은)은 화면 낭독기에 넘길 이름의 예이고, 엔진이 무엇을 받는지는 확인할 질문이다. 엔진 구현은 프로젝트의 엔진 참조 문서와 그 엔진 전문가 역할이 정한다.

#### 버튼(주)
**쓸 때**: 화면에서 가장 중요한 동작 — 「게임 시작」 · 「확인」 · 「사기」. 한 번에 하나만 보인다. 「플레이어가 여기서 가장 하고 싶은 일은?」의 답이다. **쓰지 말 때**: 다른 · 보조 동작, 결과를 되돌릴 수 없어 확인이 필요한 파괴 동작, 화면의 주된 의도가 아닌 것.

| 상태 | 보이는 것 | 입력 → 반응 | 소리 |
|---|---|---|---|
| 기본 | 진한 채움 · 아트 기준서의 주 색 · 이름 가운데 | — | — |
| 올림 | 조금 밝고 조금 큼 · 손가락 커서 | 마우스 올림 → 기본에서 바뀜 | UI 올림 |
| 초점 | 대비 큰 초점 테두리 · 밝기는 올림과 같게 | Tab · 방향 버튼 | UI 올림과 같게 |
| 누름 | 조금 작고 어둡게 | 클릭 · Enter · 패드 확인 → 누를 때 작아지고 **뗄 때 동작** | UI 확인 |
| 못 씀 | 흐림 · 올림 없음 | 반응 없음 | — |
| 처리 중 | 이름 대신 도는 표시 · 못 씀 | 두 번 보내기를 막는다 | — |

**접근성**: 키보드 — Tab으로 닿고 Enter · Space로 실행. 패드 — 방향 버튼 · 스틱으로 닿고 확인 버튼으로 실행, 화면이 열리면 주 버튼에 초점. 낭독기 — 보이는 이름과 같은 이름 · 역할 「버튼」 · 못 쓰면 「흐림」. 색약 — 주와 보조를 색만으로 가르지 않는다(채움 대 테두리 · 크기). 터치 영역 — <프로젝트 값>(대상 플랫폼 공식 지침으로 확인 · PC도 터치를 쓸 수 있으면 적용).

#### 버튼(보조)
**쓸 때**: 다른 동작 · 취소 — 「뒤로」 · 「건너뛰기」 · 「나중에」. 주 버튼과 겨루지 않고 물러나 보인다. **쓰지 말 때**: 파괴 동작(버튼(파괴)) · 화면의 가장 중요한 동작(버튼(주)).

| 상태 | 보이는 것 | 입력 → 반응 | 소리 |
|---|---|---|---|
| 기본 | 테두리만 · 보조 색 · 주보다 작거나 가볍게 | — | — |
| 올림 | 옅은 채움이 생기고 테두리가 밝아짐 | 마우스 올림 | UI 올림(주보다 부드럽게) |
| 초점 | 주와 같은 초점 테두리 | Tab · 방향 버튼 | UI 올림 |
| 누름 | 조금 작고 채움이 짙어짐 | 클릭 · Enter · 패드 취소 → 뗄 때 동작 | UI 취소 |
| 못 씀 | 흐림 | 반응 없음 | — |

**접근성**: 버튼(주)와 같다. 대화상자에 주와 함께 있으면 보통 플랫폼의 취소 입력(Esc · 패드 취소 버튼)에도 묶인다. **구현 때 볼 것**: 주와 보조의 자리를 모든 화면에서 같게 한다(가로면 주의 오른쪽 · 아래, 세로면 주 아래) — 화면마다의 멋보다 일관이 중요하다.

#### 버튼(파괴)
**쓸 때**: 되돌릴 수 없고 플레이어 데이터나 큰 진행을 잃는 동작 — 「세이브 지우기」 · 「설정 모두 초기화」 · 「경기 나가기」. 누르기 전에 모양이 위험을 알린다. **쓰지 말 때**: 되돌릴 수 있거나 결과만 큰 동작.

| 상태 | 보이는 것 | 입력 → 반응 | 소리 |
|---|---|---|---|
| 기본 | 파괴 색(색약에 맞는지 접근성 요구에서 확인) · 경고 아이콘을 둘 수 있다 | — | — |
| 올림 · 초점 | 버튼(주)와 같되 파괴 색 | — | UI 올림 |
| 누름(첫 누름) | **동작하지 않는다** · 버튼이 짧게 맥박 | 클릭 · Enter → 확인 대화상자를 연다 | UI 경고(보통 확인과 다르게) |
| 못 씀 | 흐림 | 반응 없음 | — |

**꼭 지킬 것**: 버튼(파괴)는 동작을 바로 실행하지 않고 늘 확인 대화상자를 연다. 예외는 없다 — 실수로 누른 플레이어에게 한 번 더 물러설 기회를 준다. **접근성**: 낭독기가 「<이름> 버튼 — 되돌릴 수 없다」를 읽는다(설명 칸이 있으면 거기에 경고 글). **구현 때 볼 것**: 실행할 동작은 대화상자에 넘긴다 — 버튼이 실행 논리를 들고 있지 않아야 대화상자에 버그가 있어도 잘못 실행되지 않는다.

#### 토글
**쓸 때**: 두 상태가 똑같이 옳고 지금 상태가 한눈에 보여야 하는 켬 · 끔 설정 — 「자막」 · 「조준 보조」. **쓰지 말 때**: 보기가 셋 이상(펼침 목록) · 한 번 하고 끝나는 동작(버튼) · 결과에 설명이 필요한 선택(옆에 설명을 둔다).

| 상태 | 보이는 것 | 입력 → 반응 | 소리 |
|---|---|---|---|
| 끔(기본) | 옅은 길 · 손잡이 왼쪽 · 「끔」 글 | — | — |
| 올림 · 초점 | 길이 조금 밝아짐 · 초점 테두리가 길과 손잡이를 감쌈 | 마우스 올림 · Tab · 방향 버튼 | UI 올림 |
| 켜짐 | 손잡이가 오른쪽으로 · 길이 켬 색 · 글이 「켬」 · 상태가 남음 | 클릭 · Enter · 패드 확인 → 바뀜 사건 · 값 저장 | UI 토글 켬 |
| 꺼짐 | 손잡이가 왼쪽으로 · 길이 돌아옴 | 같은 입력 | UI 토글 끔(켬과 조금 다르게) |
| 못 씀 | 흐림 · 지금 상태는 보임 | 반응 없음 | — |

**접근성**: 키보드 · 패드는 Space · Enter로 바꾼다 — 좌우 방향 입력으로 바꾸게 하지 않는다(예측하기 어렵다). 낭독기 — 역할 「switch」, 상태 「켬 · 끔」은 따로 읽으니 이름에 상태를 넣지 않는다(맞음: 이름 「자막」 + 상태 「켬」 · 틀림: 이름 「자막 켬」). 손잡이 위치만이 아니라 글이 상태를 보여야 한다. 움직임 줄이기에서는 미끄러짐 없이 바로 바뀐다.

#### 밀대
**쓸 때**: 대략의 값이면 되고 범위와 상대 위치에 뜻이 있는 값 — 음량 · 밝기 · 글자 크기. **쓰지 말 때**: 정확한 값 입력(입력칸) · 짧은 보기 목록(펼침 목록) · 켬 · 끔(토글).

| 상태 | 보이는 것 | 입력 → 반응 | 소리 |
|---|---|---|---|
| 기본 | 길 · 손잡이 왼쪽 채움 · 손잡이 · 지금 값 글 | — | — |
| 올림 · 초점 | 손잡이가 조금 커지거나 초점 테두리 · 길이 밝아짐 | 마우스 올림 · Tab · 방향 버튼 | UI 올림(초점) |
| 끌기 | 손잡이가 커서를 따르고 채움 · 값 글이 함께 바뀜 | 손잡이를 끎 → 바뀜 사건을 계속 | UI 밀대(끄는 동안) |
| 걸음 조절 | 한 걸음(<프로젝트 값>) 옮김 | 좌우 방향키 · 방향 버튼 → 걸음마다 바뀜 사건 | 걸음마다 한 번 |
| 큰 걸음 조절 | 큰 걸음(<프로젝트 값>) | Page Up · Page Down | 같은 걸음 소리 |
| 놓음 · 못 씀 | 값이 굳음 · 못 쓰면 흐리고 값은 보임 | 마우스를 뗌 → 마지막 값 사건 | — |

**접근성**: 키보드 — 방향키 작은 걸음 · Page Up/Down 큰 걸음 · Home/End 최소 · 최대. 낭독기 — 역할 「slider」, 이름은 이름표(「음악 음량」), 바뀔 때마다 값(「음악 음량, 80퍼센트」), 처음 초점 때 최소 · 최대. 모든 밀대에 숫자 값을 함께 보인다 — 채움 위치만으로는 상대 위치를 못 느끼는 플레이어가 빠진다.

#### 펼침 목록
**쓸 때**: 정해진 보기 <프로젝트 값>개 안팎에서 하나를 고르고, 닫혔을 때는 고른 값만 보이면 되는 것 — 해상도 · 언어 · 창 모드. **쓰지 말 때**: 둘 중 하나(토글) · 보기가 너무 많음(스크롤 목록) · 보기를 견주는 것이 고르는 것만큼 중요함(보기를 펼쳐 보인다).

| 상태 | 보이는 것 | 입력 → 반응 | 소리 |
|---|---|---|---|
| 닫힘 | 이름표(왼쪽) · 지금 값(오른쪽) · 아래 화살표 | — | — |
| 올림 · 초점 | 줄 배경이 옅게 · 줄 전체에 초점 테두리 | 마우스 올림 · Tab · 방향 버튼 | UI 올림 |
| 열림 | 아래에(화면 아래 끝이면 위에) 목록 · 지금 값 강조 · 초점이 그 값으로 | 클릭 · Enter · 패드 확인 | UI 펼침 |
| 목록 줄 초점 | 그 줄 강조 | 마우스 · 방향 버튼 | UI 올림 |
| 고름 | 목록이 닫히고 새 값이 보임 · 바뀜 사건 | 그 줄에서 확인 입력 | UI 고름 |
| 고르지 않고 닫음 | 닫힘 · 값 그대로 | Esc · 패드 취소 · 바깥 클릭 | UI 취소 |

**접근성**: 열렸을 때 위아래 방향키로 옮기고 Enter로 고르고 Esc로 닫는다. 첫 글자를 누르면 그 글자로 시작하는 첫 보기로 간다. 낭독기 — 역할 「combobox」, 펼침 · 접힘 상태, 초점 때 지금 값, 줄마다 값과 위치(「English, 12개 중 1」). 펼친 목록이 지금 값이나 연 부품을 가리지 않는다 — 작은 화면에서 흔한 실패다.

#### 목록 줄
**쓸 때**: 세로 스크롤 목록의 고를 수 있는 줄 하나 — 업적 · 퀘스트 기록 · 설정 분류 · 세이브 칸. **쓰지 말 때**: 2차원 격자(격자 칸) · 고를 수 없는 내용 줄(올림 · 초점 · 누름 상태를 뺀다).

| 상태 | 보이는 것 | 입력 → 반응 | 소리 |
|---|---|---|---|
| 기본 | 아이콘(선택) · 주 글 · 덧붙임 글 · 더 들어가면 화살표 | — | — |
| 올림 · 초점 | 줄 배경 강조 또는 초점 테두리(플랫폼 관례와 같게) | 마우스 올림 · 방향 버튼 · Tab | UI 올림(초점) |
| 선택됨(남음) | 더 짙은 배경 · 왼쪽 띠나 확인 표시 — 초점과 다르다(골랐지만 초점은 없을 수 있다) | — | — |
| 누름 | 짧게 밝아진 뒤 이동하거나 동작 | 클릭 · Enter · 패드 확인 | UI 확인 |
| 못 씀 | 흐림 | 반응 없음 | — |

**접근성**: 위아래로 옮긴다. 끝에 닿으면 멈춘다(돌기는 일부러 설계했을 때만). 낭독기 — 역할 「listitem」(묶음은 「list」), 이름은 주 글, 위치(「퀘스트 기록, 12개 중 3」). 최소 줄 높이 <프로젝트 값>(터치 · 패드 중심 플랫폼은 더 넉넉하게). **구현 때 볼 것**: 초점이 옮겨지면 스크롤 영역이 그 줄을 보이게 한다.

#### 격자 칸
**쓸 때**: 2차원 격자의 고를 수 있는 칸 — 인벤토리 · 능력 고르기 · 제작 재료 · 인물 고르기. **쓰지 말 때**: 한 줄짜리 내용(목록 줄) · 고를 수 없는 보기 칸.

| 상태 | 보이는 것 | 입력 → 반응 | 소리 |
|---|---|---|---|
| 빈 칸 | 옅은 테두리나 점선 — 못 씀과 다르다 | — | — |
| 찬 칸 | 아이템 아이콘 · 쌓인 수(오른쪽 아래) · 품질 표시 | — | — |
| 올림 · 초점 | 밝아짐 · 초점 테두리 · 지연 뒤 툴팁(패드는 바로 띄워도 된다) | 마우스 올림 · 방향 버튼 | UI 올림(초점) |
| 선택됨 | 굵고 대비 큰 테두리 · 확인 표시 — 초점은 다른 칸에 있을 수 있다 | 클릭 · Enter · 패드 확인 | UI 고름 |
| 누름 | 짧게 작아진 뒤 동작(장비 · 쓰기 · 살펴보기 — 화면이 정한다) | 두 번 클릭 · Enter · 패드 확인 | UI 확인 |
| 잠김 | 자물쇠 덮개 · 올림 · 초점 없음 | 반응 없음 | — |
| 끌기 출발 | 칸이 흐려지고 커서에 끄는 그림 | 끌기(마우스만) | UI 잡기 |
| 놓을 곳 | 맞는 곳은 밝게 · 틀린 곳은 경고 표시(색만이 아니게) | 끌어 올림 | 틀린 곳은 UI 오류 |

**접근성**: 방향 버튼 · 방향키로 칸을 옮긴다. 낭독기 — 역할 「gridcell」(묶음 「grid」), 이름은 아이템 이름(빈 칸은 「빈 칸」), 상태 「선택됨」 · 「흐림(잠김)」, 위치 「2줄 3칸」, 격자 크기도 알린다. 툴팁은 올림뿐 아니라 초점 때도 떠야 한다. **구현 때 볼 것**: 방향 버튼으로 위아래 · 좌우 칸을 찾는 이동은 직접 만들어야 할 수 있다.

#### 모달 대화상자
**쓸 때**: 넘어가기 전에 풀어야 할 결정 · 확인 — 뒤가 어두워지고 조작되지 않는다. 「정말인가?」 · 오류 안내. **쓰지 말 때**: 막지 않는 알림(알림) · 플레이어가 준비될 때까지 기다려도 되는 정보(도움말에 둔다) · 뒤에서 플레이가 이어져야 하는 것.

| 상태 | 보이는 것 | 입력 → 반응 | 소리 |
|---|---|---|---|
| 열리는 중 | 뒤 덮개가 어두워지고 대화상자가 가운데서 커짐(가장자리에서 오지 않는다) | 코드가 연다 → 첫 부품이나 주 버튼에 초점(파괴 동작 확인은 취소에 초점) | UI 모달 열림 |
| 열림 | 뒤는 조작 안 됨 · 모든 입력이 대화상자로 | 키보드 · 패드는 대화상자 안에서만 | — |
| 닫힘(확인) | 대화상자가 사라지고 덮개가 걷힘 | 주 버튼 → 동작 실행 · 연 부품으로 초점 | UI 확인 |
| 닫힘(취소) | 같게 사라짐 | 보조 버튼 · Esc · 패드 취소 → 동작 없음 · 연 부품으로 초점 | UI 취소 |
| 닫을 수 없음 | 막는 오류면 취소 길 없이 해결 보기만 | — | — |

**초점 가두기**: 열린 동안 Tab과 방향 버튼은 대화상자 안의 부품 사이에서만 돈다 — 뒤 내용으로 나갈 수 없다. 접근성 요구이자 UX 요구다(원문은 근거로 외부 기준의 조항 하나를 들었다 — 어느 조항인지는 접근성 요구 문서에서 확인할 질문). 닫히면 초점은 맨 위가 아니라 연 부품으로 돌아간다. **접근성**: 역할 「dialog」 · 이름은 제목(모든 대화상자에 제목이 있어야 한다 — 보이지 않게 두더라도) · 열 때 제목과 첫 부품을 읽는다. Enter는 초점이 있는 버튼을 누른다 · 확인 대화상자의 처음 초점은 취소 · Esc는 늘 취소. 움직임 줄이기에서는 커짐 없이 바로, 덮개는 더 짧은 페이드.

#### 확인 대화상자
**쓸 때**: 파괴 동작 확인 — 늘 버튼(파괴)가 연다. 보기는 딱 둘(동작 이름이 붙은 확인 · 취소). **쓰지 말 때**: 파괴가 아닌 확인 · 결정이 필요 없는 오류 · 알림 · 동작이 셋 이상.

**이름 규칙**: 확인 버튼은 「확인」 · 「예」가 아니라 그 동작이다 — 「세이브 지우기」 · 「경기 나가기」. 글을 빨리 못 읽는 플레이어의 실수를 줄인다.

**구조**: 제목 — 짧게, 동작을 말한다(「정말인가?」가 아니라 「세이브를 지울까?」) · 본문 — 결과 한 문장(「되돌릴 수 없다.」) · 확인 — 버튼(주), 동작 이름 · 취소 — 버튼(보조), 「취소」 · 처음 초점 — 취소(더 안전하다).

**접근성**: 모달 대화상자를 모두 따른다. 낭독기가 「경고 대화상자, <제목>」으로 파괴 맥락을 알린다. 처음 초점이 취소인 것은 고를 일이 아니라 요구다. 처음 열린 상태에서 Enter 한 번은 취소를 누르며 지우기를 실행하지 않는다.

#### 알림(토스트)
**쓸 때**: 결정이 필요 없는 짧고 막지 않는 정보 — 「저장했다」 · 「업적 달성」 · 「가방이 가득 찼다」. 플레이는 이어지고 알림은 저절로 사라진다. **쓰지 말 때**: 결정이 필요한 정보(모달) · 플레이어가 무언가 해야 하는 오류 · 놓치면 안 되는 정보.

| 상태 | 보이는 것 | 입력 → 반응 | 소리 |
|---|---|---|---|
| 들어옴 | 화면 가장자리에서 미끄러져 들어옴(보통 주 동작 영역에서 먼 구석) | 코드가 띄움 | 알림 종류의 소리 |
| 보임 | 아이콘 · 제목 · 본문(선택) · 닫기(선택) | 포인터를 올리면 저절로 닫힘 시계가 멈춤 | — |
| 저절로 닫힘 | 흐려지며 나감 | 시계가 다 됨(한 줄 · 두 줄마다 <프로젝트 값>) → 대기열에서 뺌 | — |
| 손으로 닫음 | 바로 나감 | 닫기 · 터치 밀기 | UI 취소(작게) |
| 대기열 넘침 | 새 알림이 가장 오래된 것을 일찍 밀어냄 | 보이는 중 새 알림 → 먼저 온 순서 · 동시 최대 <프로젝트 값> | — |

**접근성**: 초점을 옮기지 않고 낭독기가 읽어야 한다 — 엔진의 접근성 알림 기능이 필요하고, 되는지는 엔진 참조 문서로 확인한다. 움직임 줄이기에서는 미끄러짐 없이 페이드만. 플레이어가 무언가 해야 하는 정보의 유일한 길로 쓰지 않는다 — 그런 정보는 남아 있는 UI에도 둔다. 저절로 닫히는 시간은 <프로젝트 값> 이상으로 두고, 더 늘리는 설정을 둘지 본다(처리가 느린 플레이어).

#### 툴팁
**쓸 때**: 보이는 이름에 덧붙이는 정보 — 인벤토리 아이템 설명 · 능력치 풀이 · 접근성 설정 설명. 플레이어는 읽지 않고도 넘어갈 수 있어야 한다. **쓰지 말 때**: 동작을 끝내려면 꼭 읽어야 하는 정보(이름이나 본문에 둔다) · 올림이 없는 터치 전용 플랫폼(정보 버튼이 설명 창을 열게 한다).

| 상태 | 보이는 것 | 입력 → 반응 | 소리 |
|---|---|---|---|
| 숨음 · 올림 계기 · 초점 계기 | — | 마우스가 들어옴 · 부품이 초점을 받음 → 지연 시계 시작(초점은 일부러 옮긴 것이라 더 짧게) | — |
| 나타남 · 보임 | 부품 가까이(위를 먼저 · 가장자리면 비켜서) 제목(선택) · 본문 · 최대 너비 <프로젝트 값> | 시계가 다 됨 | — |
| 숨는 중 | 흐려짐 | 마우스가 나감 · 초점이 옮겨 감 | — |

**접근성**: 올림 없이도 내용에 닿아야 한다 — 부품의 이름에 가장 중요한 툴팁 정보를 담고, 전체 글은 설명 칸에 두며, 초점 때 읽는다. 지연은 실수로 뜨는 것을 막는다 — 바로 뜨는 툴팁은 패드 이동을 방해한다. 툴팁 글은 본문 글과 같은 대비 기준(<프로젝트 값>)을 지킨다.

#### 진행 막대
**쓸 때**: 정해진 끝을 향한 직선 진행 — 불러오기 · 다음 레벨까지 경험치 · 셀 수 있는 퀘스트 목표(「적 10 중 3」). **쓰지 말 때**: 원형 진행(따로 패턴) · 빠르게 오르내리는 값(체력 · 자원 막대) · 끝이 없는 값.

| 상태 | 보이는 것 | 입력 → 반응 | 소리 |
|---|---|---|---|
| 기본 | 길 · 왼쪽에서 오른쪽 채움 · 값 글(비율이나 N/M) | — | — |
| 값이 오름 | 채움이 새 값까지 부드럽게 | 값이 바뀜 | 맥락에 따라(경험치는 소리 · 불러오기는 없음) |
| 최대 | 끝까지 참 · 끝맺는 움직임(선택) | 끝 → 완료 사건 | 어울리면 완료음 |
| 0 · 끝을 모름 | 채움 없음 · 끝을 모르면 조각이 도는 반복 | — | — |

**접근성**: 역할 「progressbar」 · 이름은 진행하는 것(「경험치」) · 값은 숫자 · 비율 · 최대를 함께(「경험치, 1000 중 450, 45퍼센트」) · 큰 변화 때만 읽는다. 채움 색만이 아니라 숫자 이름표를 둔다. 끝을 모르면 「불러오는 중」만 읽는다. 움직임 줄이기에서는 반복이 멈춘 표시로, 부드러운 채움은 바로 바뀜으로.

#### 입력칸
**쓸 때**: 글 입력 — 새 세이브의 이름 · 목록 검색 · 키 바꾸기(입력한 글이 아니라 누른 키를 보인다) · 정확한 숫자. **쓰지 말 때**: 정해진 보기 고르기(펼침 목록 · 목록) · 콘솔 중심 흐름(화면 키보드는 마찰이 크다 — 글 입력을 줄인다).

| 상태 | 보이는 것 | 입력 → 반응 | 소리 |
|---|---|---|---|
| 기본 · 올림 | 테두리 · 옅은 자리 글 · 올림 때 테두리가 조금 밝아짐 | 마우스 올림 | — |
| 초점 · 입력 중 | 테두리가 밝아지고 깜박이는 커서 · 자리 글 숨음 · 글자가 나타남 | Tab · 클릭 → 콘솔 · 모바일은 화면 키보드 · 키 입력 | UI 올림 · 키 소리(선택) |
| 값 있음 · 지우기 | 값이 보이고 오른쪽에 지우기 버튼 | 지우기 → 값이 비고 버튼이 사라짐 | UI 취소(작게) |
| 글자 수 한도 | 더 받지 않음 · 짧게 흔들리거나 한도 표시가 바뀜(선택) | 한도에서 입력 → 거절 | UI 오류(작게) |
| 검사 오류 · 통과 | 오류 테두리와 칸 아래 오류 글 · 통과 표시(선택) — 색만이 아니게 | 보낼 때 · 초점이 떠날 때 | 오류는 UI 오류 |
| 못 씀 | 흐림 · 값은 보임 | — | — |

**접근성**: 보통 편집 단축키(Home · End · 모두 고르기 · 복사 · 붙이기 · 되돌리기). 낭독기 — 역할 「textbox」 · 이름은 자리 글이 아니라 이름표 · 지금 값 · 한도에 닿으면 알림 · 검사 오류는 생기는 즉시. 자리 글을 유일한 이름표로 쓰지 않는다 — 입력하면 사라져 기억이나 인지가 힘든 플레이어가 헷갈린다. 칸 위나 옆에 보이는 이름표를 둔다.

#### 탭 줄
**쓸 때**: 한 화면의 내용을 구역으로 나눠 한 번에 하나만 보일 때 — 캐릭터(능력치 · 장비 · 능력) · 설정(플레이 · 그래픽 · 소리 · 접근성). 탭이 <프로젝트 값>개를 넘으면 옆 목록 이동을 생각한다. **쓰지 말 때**: 탭이 너무 많음 · 함께 보여야 할 내용 · 다른 화면으로 가는 이동(화면 쌓기).

| 상태 | 보이는 것 | 입력 → 반응 | 소리 |
|---|---|---|---|
| 안 고른 탭 · 고른 탭 | 탭 이름 · 고른 탭은 밑줄 · 채움 · 대비 배경과 그 내용 | — | — |
| 올림 · 초점 | 배경이 옅게 · 탭 이름에 초점 테두리 | 마우스 · 탭 줄 안 Tab · 좌우 방향 버튼 | UI 올림(초점) |
| 바꿈 | 고른 표시가 옮겨 가고 내용이 바뀜(페이드 · 미끄러짐) | 클릭 · Enter · 패드 확인 | UI 탭 |
| 숄더 버튼 | — | 패드 왼쪽 · 오른쪽 숄더 → 앞 · 다음 탭(플랫폼 관례) | UI 탭 |

**접근성**: 탭 줄 안에서는 좌우 방향키로 탭을 옮기고 Tab은 아래 내용으로 들어간다. 낭독기 — 탭은 「tab」, 묶음은 「tablist」, 내용은 「tabpanel」 · 고른 탭은 「선택됨」 · 내용의 이름은 그 탭. 고른 탭은 색만이 아니라 밑줄 · 채움 · 굵기로도 구분한다. **구현 때 볼 것**: 숄더 버튼 단축키는 화면이 직접 받아야 할 수 있다.

#### 스크롤 영역
**쓸 때**: 영역에 다 안 들어가는 내용 — 인벤토리 목록 · 설정 글 · 제작진 · 긴 설정 목록. 스크롤 표시가 더 있다는 것을 알린다. **쓰지 말 때**: 쪽으로 나누는 게 나은 내용(빽빽한 목록 이동은 쪽이 더 또렷할 수 있다) · 끝없는 스크롤(늘 불러오는 상태와 끝 상태를 둔다).

| 상태 | 보이는 것 | 입력 → 반응 |
|---|---|---|
| 다 들어감 · 스크롤 가능 | 막대 없음(아트 방향에 따라 늘 보일 수도) · 넘치면 오른쪽 막대, 손잡이 크기는 보이는 비율 | — |
| 마우스 · 막대 끌기 | 내용과 손잡이가 함께 움직임 | 휠 → 한 칸에 <프로젝트 값>줄(OS 설정을 따를 수 있다) · 손잡이 끌기 |
| 키보드 · 패드 스크롤 | 한 줄씩 · 초점 받은 줄이 보이게 | 영역에 초점이 있고 안 부품엔 없을 때 위아래 · 보이는 곳 밖으로 방향 버튼 이동 |
| 끝 · 초점 따라 스크롤 | 끝에서 멈춤 · 안 부품이 초점을 받으면 다 보이게 스크롤 | 끝에 닿음 · 안 부품이 초점을 받음 |

**접근성**: 키보드 · 패드는 막대를 직접 다루지 않아도 된다 — 안 줄을 옮기면 저절로 스크롤해 초점 줄이 보인다. 낭독기 — 「스크롤 가능」과 위치(「30개 중 5~15 표시」)를 알린다 — 엔진 접근성 기능이 필요하니 엔진 참조 문서로 확인한다. 가장자리를 흐리는 표시는 도움이 되지만 내용이 더 있다는 유일한 표시가 되면 안 된다 — 스크롤 막대를 둔다.
