> **쓰는 법** — 누가 채우나: 릴리스 매니저 · QA 테스터(받은 빌드를 깔아 보거나 브라우저에서 해 본 결과) · 언제: itch.io 배포가 정해진 뒤, 출시 점검표(`templates/release-checklist-template`) · 출시 준비표(`templates/launch-checklist`)의 인증 칸에 옮겨 붙인다 · 줄여도 되는 절: 실제로 쓰지 않는 빌드 종류 · 올리는 방법의 줄은 「해당 없음(이유)」 · 사람이 정할 것: 올리기 · 페이지 공개(배포 · 게시 — 되돌리기 어려운 일) · 가격(돈) · 연령 · 내용 태그(게임 내용).
>
> 총괄은 이 글과 함께 `templates/release-checklist-template`를 꺼낸다. 정식 출시에서는 `templates/launch-checklist`도 꺼내며, 프로젝트 문서 경로를 맡기는 글에 적는다.
>
> 올리는 방법은 프로젝트가 실제로 쓰는 것만 고른다(예: 웹 화면에서 올리기 · itch.io의 명령 줄 올리기 도구) — 특정 도구를 쓰라고 하지 않는다. 올리기 한도와 규칙은 「최신 공식 요구를 확인했나(언제 · 어디서)」 칸으로 남긴다. 채운 문서에서는 이 칸을 지운다.

# 인증 — itch.io

| 항목 | 최신 공식 요구를 확인했나(언제 · 어디서) | 판정 | 근거 · 이유 |
|---|---|---|---|
| 빌드 크기가 itch.io 올리기 한도 안이다(<공식 문서로 확인한 한도>) | | | |
| itch.io 페이지 완성 — 표지 그림 · 스크린샷 · 설명 · 태그 | | | |
| 연령 · 내용 태그를 정직하게 달았다 | | | |
| 내려받는 빌드와 브라우저 빌드 가운데 무엇을 낼지 정했고 시험했다 | | | |
| 올리는 방법: <웹 화면 · 명령 줄 도구 · 기타>. 명령 줄 도구를 쓰면 올리는 기기마다 채널 이름이 맞다 | | | |
| 공개 범위 — 「숨김」 · 「비밀 링크」가 누구에게 보이는지 공식 문서로 확인해 적는다(숨김을 비공개로 읽지 않는다) | | | |

판정 칸: 통과 · 실패 · 못 봄 · 해당 없음(이유). 아직 정하지 않은 것은 「못 봄 — 아직 안 정함」으로 적는다.
