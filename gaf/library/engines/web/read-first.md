## 이 참조는 무엇인가
- `engines/web/` 의 글 6개는 공개 저장소 claude-code-game-studios(v1.3.0 · MIT)의 엔진 참조를 받은 그대로 둔 영어 글이다. 출처와 라이선스는 서랍의 `NOTICE.md` 에 있다.
- 이 프레임워크에서 브라우저 · 도구 · 라이브러리를 돌려 확인한 글이 아니다. 판 · API · 예제 · 실측 기록은 모두 원문 저자가 한 말이다.
- 원문은 항목마다 근거 등급을 붙였다. **[S]** 는 그날 1차 출처에서 읽었다, **[M]** 은 실제 기기에서 쟀다, **[J]** 는 출처에 없는 판단이다. 이것도 원문 저자의 주장이지 이 틀의 실측이 아니다.
- 그래서 후보로만 쓴다. 프로젝트에 설치된 판에서 확인한 것만 구현 · 검사의 근거로 삼는다.
- 이 글은 원문 `VERSION.md` 의 판과 날짜를 옮긴 것이다. 원문 `VERSION.md` · `README.md` 는 서랍에 넣지 않았다(그쪽 작업 흐름과 모델 학습일 단정이 섞여 있다).

## 원문이 밝힌 판과 날짜
아래는 원문 `VERSION.md` 의 주장이다. 이 틀이 확인한 사실이 아니다.

- 원문은 「웹」이 엔진 하나가 아니라고 한다. 도구 묶음(Vite + TypeScript, 기본은 Canvas 2D와 Web Audio)에 게임이 라이브러리를 더한 것이다. 게임이 쓰는 라이브러리는 설정이 아니라 그 게임의 `package.json` 에서 읽는다고 한다.
- 이 판들은 그쪽 시작 틀이 고정해 쓰는 판이다. 프로젝트의 판이 아니다. 설치된 판은 프로젝트마다 잠금 파일이 정한다.

- 원문도 경고한다. 이 표는 시작 틀의 판이다. 있던 웹 프로젝트는 자기 판을 쓰며, 더 오래된 판(Vite 5 · Phaser 3 · PixiJS 7)이거나 더 새 판일 수 있다. 판에 묶인 주장을 믿기 전에 잠금 파일의 그 패키지 항목이나 `node_modules/<패키지>/package.json` 에서 실제 판을 읽는다. Phaser 3 프로젝트에는 Phaser 3 코드가 필요하다.

## 쓰는 법
1. 프로젝트의 잠금 파일(`package-lock.json` 등)에서 실제로 설치된 도구 · 라이브러리 판과 Node 판을 먼저 적는다. 대상 브라우저 · 기기도 적는다.
2. 맡은 일에 필요한 글만 읽는다(도구는 `breaking-changes`, 브라우저 규칙은 `current-best-practices`, 라이브러리는 그 라이브러리 글).
3. 참조의 API · 설정 · 예제는 그 판에서 빌드 · 실행해 본 뒤에 쓴다. 브라우저 동작은 대상 브라우저 · 기기에서 본다.
4. 「사라졌다 · 폐기됐다 · 바꾸는 것이 좋다」를 가른다. 표만 보고 일괄 치환하지 않는다.
5. 확인하지 못한 것은 보고에 「확인 안 됨」으로 적는다. 보지 못한 브라우저 · 기기도 그렇게 적는다.

## 알려진 의심
2026-11-16 전수검사(`docs/조사/ccgs-전수/engines/정리.md` 2절 · 4절)가 짚은 것이다. 전수검사도 인터넷이나 설치된 도구로 다시 확인하지는 않았다. 줄 번호는 받은 저장소 커밋 abc0de79의 원문 파일 기준이다. 서랍 글에는 머리말 9줄이 붙어 있어 원문 N줄은 서랍 글의 N+9줄이다.

| 어느 글 | 무엇이 의심스러운가 | 어떻게 다루나 |
|---|---|---|
| 원문 `VERSION.md`(13줄 · 48~50줄 · 이 글의 위 표) · 모든 글의 머리 | 「2026-10-29에 모두 확인했다」는 것은 원문 저자의 주장이다. | 이 틀이 확인한 날로 쓰지 않는다. 이 틀이 읽은 날(2026-11-16)을 API 확인일로 덮어쓰지도 않는다. |
| `engines/web/phaser`(원문 5~8줄) · `engines/web/threejs`(원문 5~7줄) · `engines/web/pixijs`(원문 5~8줄) · `engines/web/breaking-changes`(원문 5~6줄) · 원문 `VERSION.md`(54~64줄) | 모델이 특정 판까지만 안다고 단정한다(예: Phaser 3.88 · three.js r176). | 모델(Claude · Codex)마다 다르다. 학습일 대신 실제 프로젝트 판과 확인한 API로 고른다. |

| `engines/web/threejs`(원문 19~20줄) | 그쪽 한 파일 시제품이 전역 `THREE` 로 같은 판을 쓴다는 연결이 있다. 패키지를 자동으로 더하라는 지시가 있다. | 그 연결은 이 틀에 없다. 패키지는 자동으로 더하지 않는다. API 이름 · 시간 단위 · 소스 태그는 그대로 둔다. |
