이 시트의 기본값은 추천이다. 게임 내용은 사람이 정한다.
두 장르 이상을 섞는 생각일 때만 꺼낸다. 섞은 게임은 섞인 장르마다 시트의 줄을 모두 가져온 뒤, 시스템마다 따로 주인을 정한다. 한 장르가 게임 전체를 맡을 필요는 없다. 장르 시트의 「다른 장르와 섞을 때」가 그 장르가 무엇의 주인인지 말한다.

## 순서
1. **장르마다 가져오는 것을 적는다.** 겉모습(그 장르를 알아보게 하는 인물 · 땅 · 색)과 화면(그 장르의 플레이어가 가장 먼저 찾는 부분)에 저마다 무엇을 가져오는지 적고, 참고 작품도 장르마다 하나씩 둔다.
2. **두 장르가 실제로 만나는 한 장면을 먼저 확인한다.** 한 장르의 동사가 다른 장르의 시스템을 바꾸는 한 순간이다. 기획의 「처음 1분」은 이 장면에서 끝나고, 만들 때도 두 장르를 따로 세우기 전에 이 장면부터 되게 한다.
3. **시스템마다 주인을 정한다** — 아래 담당표. 사람의 말이 먼저다. 말이 없으면 표의 기준으로 권장안을 내고 사람에게 올린다.
4. **충돌은 사람이 고른다.** 두 장르가 반대를 원하면 그 시스템 줄에 저마다 원한 것과 이 게임이 하는 것을 적는다. 아래 「충돌」의 해법은 권장안이다.
5. **알려진 조합이면** 그 「살필 것」을 검사 칸에 옮긴다.

만나는 장면의 예:
- 리듬 + 액션 로그라이트: 박자에 맞은 공격이 다음 곡을 고르는 게이지를 채운다. 박자 줄과 빌드 선택이 한 화면에 있다.
- 플랫포머 + 격자 퍼즐: 점프가 퍼즐 조각을 움직이는 칸에 내려앉는다. 레벨 목표와 남은 수가 플레이어 곁에 있다.
- 턴제 전략 + 경영 타이쿤: 일군 타일의 물건이 법이 값을 바꾸는 시장에 닿는다. 지도의 산출과 시장 창이 한 턴 차이다.

## 담당표 — 빈칸을 채워 쓴다
| 시스템 | 말이 없을 때 주인 | 주인 장르 | 충돌 | 사람의 결론 | 검사 |
|---|---|---|---|---|---|
| 만나는 장면 | 한 장르의 동사가 다른 장르의 시스템을 바꾸는 곳 | | | | |
| 입력과 시점 | 플레이어가 가장 자주 되풀이하는 동사의 장르 | | | | |
| 죽음 · 체크포인트 · 저장 | 생각이 원하는 걸린 것의 장르 | | | | |
| 성장 · 빌드 · 경제 | 한 판이나 하루를 가르는 결정의 장르 | | | | |
| 규칙(수가 하는 일 · 이기는 법 · 되돌리기) | 퍼즐이나 결투를 가진 장르 | | | | |
| 적과 위협 | 생각이 다루는 위험의 장르 | | | | |
| 구조(레벨 · 한 판 · 하루 · 열린 곳 하나) | 한 번 하는 게임의 꼴을 정하는 장르 | | | | |
| 누가 움직이고 누가 말하나(여럿이 할 때) | 사람들이 함께하는 형식을 가진 장르 | | | | |

- 겉모습 · 주제 · 배경은 이 가운데 어느 것도 정하지 않는다.
- 주인을 정한 시스템은 그 장르의 줄을 따르고, 다른 장르의 그 시스템 줄은 뺀다. 한 장르의 줄을 통째로 버리지 않는다.

## 알려진 조합
- **플랫포머 + 격자 퍼즐 · 논리 퍼즐**: 플랫포머가 움직임과 시점을, 퍼즐이 규칙 · 레벨로 가르치기 · 되돌리기 · 해답 확인을 맡는다. 살필 것: 너그러운 움직임으로 점프가 퍼즐을 건너뛰지 못한다. 퍼즐 플랫포머 시트가 이 조합이다.
- **메트로배니아 + 탐정**: 메트로배니아가 이동과 이어진 지도를, 탐정이 증거와 알면 열리는 것을 맡는다. 살필 것: 아직 없는 능력과 이미 알아낼 수 있던 규칙을 구별되게 한다.
- **액션 RPG · 소울라이크 + 캐릭터 액션**: 액션이 타이밍 · 겨냥 · 시점을, RPG가 빌드 · 레벨 · 장비를, 걸린 것이 체크포인트를 맡는다. 살필 것: 강화한 뒤에도 맞히기와 살아남기가 중요하다.
- **트윈 스틱 슈터 + 액션 로그라이트 · 서바이버라이크**: 쏘기와 움직임이 손맛을, 조합이 빌드를, 한 판이 남는 것과 잃는 것을 맡는다. 살필 것: 조합이 커져도 조준과 위협이 읽힌다.
- **덱빌딩 로그라이크 + 택티컬 RPG**: 택티컬이 공간과 적의 의도를, 덱이 뽑기 · 빼기 · 소멸 · 빌드를 맡는다. 살필 것: 행동이 하는 일을 정확히 보여 주고, 이번 싸움에 쓴 카드와 영영 사라진 카드를 구별한다.
- **도시 건설 + 액션 로그라이트**: 도시가 배치 · 일꾼 · 서비스 · 잘못되는 곳을, 한 판이 끝과 남는 것을 맡는다. 살필 것: 버리는 도시 없이 끝이 분명하다.
- **생존 크래프팅 + 코지 정리 · 샌드박스**: 생존이 바깥의 욕구와 위험을, 코지한 짓기가 배치 · 꾸미기 · 내 것 만들기를 맡는다. 살필 것: 위험이 집까지 얼마나 오는지는 사람이 고른다.
- **농장 생활 시뮬레이션 + 경영 타이쿤**: 생활 시뮬레이션이 하루와 사람들을, 경영이 물건의 흐름과 잘못되는 곳을 맡는다. 살필 것: 하루 뒤에 멈춰도 안전하다.
- **샌드박스 · 스텔스 + 액션 어드벤처(열린 세계의 이머시브 심)**: 시뮬레이션이 늘 같게 작동하는 상호작용과 여러 풀이를, 열린 세계가 랜드마크 · 채움 · 일정 · 바뀐 채 남는 것을 맡는다. 살필 것: 큰 지도는 서로 얽히는 시스템을 대신하지 않는다. 시스템끼리 얽힌 생각이면 핵심 행동은 제대로 만들고, 나머지 시스템은 얇게 서로 이어 둔 뼈대로 먼저 세운다.
- **스텔스 + 물리 퍼즐(부수는 하이스트)**: 스텔스가 알려진 것과 들키는 것을, 하이스트가 계획과 결행을, 부수기가 길 바꾸기를 맡는다. 살필 것: 계획에서 탈출로 넘어가는 때가 분명하고, 부순 것은 남는다.
- **서바이벌 호러 + 1인칭 슈터**: 공포가 알 수 있는 것과 긴장을, 슈터가 조준과 총의 반응을, 생존이 부족함과 가방을 맡는다. 살필 것: 봐주는 규칙도, 들킨 벌도 모두 겹치지 않는다.
- **협동 + 서바이벌 호러 · 파티 게임**: 공포가 가까운 위협을, 협동이 말하기 · 구조 · 저마다의 몫 · 다시 일어나기를 맡는다. 살필 것: 웃음에도 모두가 따라갈 수 있는 결과가 있다.
- **익스트랙션 + 액션 RPG**: 익스트랙션이 남기거나 잃는 것을, 슈터가 싸움을, RPG가 장비와 그 값을 맡는다. 믿을 만한 거래는 온라인 플레이 몫이다(서버가 필요하다). 살필 것: 가지기 · 잃기 · 되찾기를 따로 설명한다.
- **레이싱 + 액션 RPG · 샌드박스**: 레이싱이 조작감과 공정한 타임 어택을, RPG가 성장을, 샌드박스가 세계의 할 일을 맡는다. 살필 것: 경주의 따라잡기 규칙을 타임 어택에 넣지 않는다.
- **아케이드 스포츠 + 대전 격투**: 스포츠가 득점과 경기 흐름을, 격투가 커맨드 입력 · 회복 · 방어 · 겨루기를 맡는다. 살필 것: 도움과 입력 관용이 두 편에 같고, 두 편 다 볼 수 있다.
- **리듬 + 캐릭터 액션 · 벨트스크롤 액션**: 리듬이 타이밍 판정을, 액션이 빠른 입력과 타격의 효과를 맡고, 소리는 음악의 시계를 따른다. 살필 것: 그림을 박자에 맞추려고 입력을 늦추지 않는다.
- **논리 퍼즐 · 격자 퍼즐 + 비주얼 노벨 · 워킹 시뮬레이터**: 퍼즐이 지켜지는 규칙을, 이야기가 되풀이하는 행동의 뜻을 맡는다. 살필 것: 뜻이 바뀌기 전에 조작을 가르친다.
- **턴제 전략 + 비주얼 노벨(인물 드라마가 있는 전략)**: 전략이 경제와 영토를, 인물이 스트레스 · 유대 · 사건을 맡는다. 살필 것: 플레이어가 아는 것과 인물이 아는 것을 나누고, 결과마다 원인을 따라갈 수 있다.
- **레벨 메이커 + 물리 퍼즐 · 샌드박스**: 편집기가 편집 · 되돌리기 · 서로 기대는 것 · 공유 전 레벨 확인을, 물리가 함께 쓰는 규칙을 맡는다. 누가 편집할지는 온라인 플레이 몫이다(서버가 필요하다). 살필 것: 만든 사람의 클리어는 길이 있다는 증거이지 공정하다는 증거가 아니다.
- **항해 + 생존 크래프팅 + 협동**: 항해가 바람 · 뜨기 · 배의 움직임 · 조준을, 생존이 노출과 물자를, 협동이 손보기와 말하기를 맡는다. 살필 것: 보이는 물이 배를 움직이는 물이다.
- **코지 정리 + 탐정 + 비주얼 노벨**: 코지가 너그러운 다루기와 압박 없는 마무리를, 추리가 증거를, 이야기가 소지품과 장소의 뜻을 맡는다. 살필 것: 힌트가 추리를 남기고, 너그러운 마무리가 퍼즐을 지우지 않는다.

## 충돌 — 결론은 사람이 고른다
- **무거운 결행 대 즉시 취소**: 동작마다 고르고, 언제 취소되는지 보여 준다.
- **숨은 도움 대 공정한 겨루기**: 기기와 모드에 맞춘 도움, 겨루는 곳에서는 드러내 말한다.
- **중요한 실패 대 쉬운 다시 하기**: 무엇이 처음으로 돌아가고 무엇이 남는지, 어떻게 안전하게 끝내는지 말한다.
- **도우미 대 저절로 굴러가는 파티**: 생각이 필요로 하는 곳에서만 타격 · 구하기 · 마무리 한 방을 플레이어 몫으로 남긴다.
- **끝없는 성장 대 읽히는 숫자**: 셈과 서로를 부르는 고리에 상한을 두고, 크게 터지는 빌드는 남긴다.
- **모르는 것 대 풀 수 있는 계획**: 무엇이 보이고 · 정해졌고 · 운에 맡겼고 · 숨었는지 말한다.
- **분위기의 카메라 대 플레이어의 조작**: 플레이어가 넘겨받을 수 있는 구도, 경고는 모두 시야 안에.
- **차례대로의 볼거리 대 빠른 다시 하기**: 일어나는 차례는 지키고, 빨리 감거나 건너뛸 수 있게 한다.
- **내일의 기대 대 계속하라는 압박**: 분명히 저장된 상태와, 기다려 주는 알림.
- **자유로운 짓기 대 확인되는 도전**: 끝내는 것이 핵심인 곳은 완료를 확인하고, 자유로운 짓기는 자유롭게 둔다.
